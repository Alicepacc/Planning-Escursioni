# Mockup della nuova UI (20/11/2026)

Due direzioni visive sugli stessi tre schermi, con dati veri del catalogo (Monte Mulaz, Lago
Coldai, Bivacco Bedin…), a misura di iPhone 15 Pro. Le percentuali di affidabilità sono
d'esempio: il punteggio vero arriva dal calcolo (ADR 0015).

| File | Cosa mostra |
|---|---|
| `confronto-A-rifugio.jpg` | A «Rifugio»: carta calda, verde bosco, titoli con grazie (Fraunces) |
| `confronto-B-quota.jpg` | B «Quota»: bianco ghiaccio, blu alpino, titoli geometrici (Manrope), anche in tema scuro |
| `*-home.png` | «Scopri»: ricerca, scorciatoie, avviso di primo uso, uscite CAI in programma, itinerari |
| `*-esplora.png` | «Mappa»: mappa con i punti, filtri rapidi, elenco a scomparsa |
| `*-scheda.png` | Scheda: mappa, numeri chiave, profilo, perché la traccia è affidabile, tappe, «Organizza un'uscita» |

Navigazione proposta: quattro schede in basso (Scopri, Mappa, Pianifica, Uscite), profilo
dall'avatar in alto. Difficoltà a colori come le piste (T verde, E blu, EE rosso, EEA nero,
EAI viola). `mockup.html` rigenera le immagini (`?theme=a|b|bd&screen=home|esplora|scheda`).
