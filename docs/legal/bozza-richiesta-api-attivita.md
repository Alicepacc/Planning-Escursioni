**Oggetto**: Richiesta di accesso all'API delle attività sezionali (organizzazione.cai.it)

Gentili,

vi ringrazio per la risposta sull'uso dei dati OSM2CAI. Sto sviluppando Cordata, una web-app
gratuita e senza pubblicità per programmare escursioni con dati aperti, che citerà sempre il CAI
come fonte e rimanderà alle pagine delle sezioni per l'iscrizione alle gite.

Ho notato che `organizzazione.cai.it` espone un'interfaccia REST delle attività sezionali
(`/wp-json/cai-activities/v1`, con ricerca per regione, sezione, difficoltà e date), oggi
riservata ai siti del CAI. Vorrei chiedervi se è possibile usarla per mostrare le gite in
programma, alle seguenti condizioni:

- solo i dati pubblici dell'attività (titolo, data, sezione, difficoltà, località, link alla
  pagina ufficiale), mai dati personali di accompagnatori o partecipanti;
- poche richieste al giorno, con cache e un identificativo dell'applicazione;
- attribuzione «Attività: CAI Sezione di …» con link alla fonte;
- nessuna gestione delle iscrizioni, che restano sui canali delle sezioni.

Se non è possibile, continuerò a basarmi sui programmi pubblicati dalle sezioni, riportandone
solo una sintesi con il link all'originale, come indicato nella vostra risposta.
